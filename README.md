# Dependency Visualizer — визуализатор графа зависимостей

Учебный проект: инструмент визуализации графа зависимостей
для менеджера пакетов (Вариант 29). Этап 5 — визуализация.

Готовые средства (менеджеры пакетов, библиотеки) для получения
зависимостей не используются. Формат пакетов — Python (pip).

## Требования

- Python 3.10 или выше
- Запуск из корня проекта

## Быстрый старт

```bash
python3 -m src.visualizer \
    --package A \
    --repo repo/graph_diamond.txt \
    --test-mode on \
    --package-version 1
```

На экран печатается описание графа на языке Mermaid:

```mermaid
graph LR
  A["A"]
  B["B"]
  A --> B
```

| Параметр            | Назначение                                 |
|---------------------|--------------------------------------------|
| `--package`         | Имя анализируемого пакета                  |
| `--repo`            | URL или путь к тестовому репозиторию       |
| `--test-mode`       | Режим тестового репозитория (`on`/`off`)   |
| `--package-version` | Версия пакета                              |
| `--reverse`         | Обратные зависимости заданного пакета      |

## Три пакета

Тестовый репозиторий:

```bash
./os_scripts/test_mermaid.sh
```

- `A` в `repo/graph_diamond.txt` — транзитивный ромб
- `C` в `repo/graph_chain.txt` — хвост цепочки
- `B` в `repo/graph_cycle.txt` — пакет внутри цикла

Реальный индекс PyPI, без тестового режима:

```bash
./os_scripts/test_mermaid_real.sh
```

Пакеты: `flask` 3.0.3, `click` 8.1.7, `blinker` 1.8.2.

## Сравнение с инструментами pip

У pip нет штатной команды, которая рисует граф. Ближайший
распространённый просмотр зависимостей — `pipdeptree`: он
показывает дерево уже установленных пакетов.

Расхождения с нашим выводом ожидаемы:

- Мы читаем метаданные заданной версии с PyPI или из тестового
  файла. `pipdeptree` смотрит только то, что установлено
  в текущем окружении.
- Зависимости с маркером `extra` отбрасываются. Зависимости
  с маркером версии Python остаются: спецификатор окружения
  не вычисляется. pip такой пакет может не установить.
- Имена не схлопываются по регистру: `markupsafe` и
  `MarkupSafe` становятся двумя узлами. pip считает их
  одним пакетом.
- Если в метаданных нет точной версии `==`, для обхода
  берётся актуальная версия с индекса. Разрешение pip
  может выбрать другую подходящую версию.
